## Direction contract

THESIS: Rogelio's rigor is legible before a word is read — the résumé of an SDET who builds developer tooling reads like the developer documentation he'd ship, not a résumé wearing a template. Refuses both the card-grid/hero-photo portfolio default and the dark-terminal AI-portfolio cliché.

OWN-WORLD: A Stripe/Next.js-docs register — warm-white surface, near-black ink, one restrained indigo-blue accent reserved for links, active nav, and status. Persistent left sidebar nav + right content column on desktop, collapsing to a top drawer on mobile. Content ships in doc "panels": bordered, line-numbered monospace code-block panels for the AIDLC pipeline and real script excerpts; endpoint-table panels for skills; a changelog-style vertical list for experience. Quantified achievements render as calibrated tick/graticule readouts (a measured scale with a marked value), never a generic stat card. Status chips ("Available for new opportunities", "Migration in progress") encode state via icon shape and weight; color is secondary, never the only signal.

STORY: A hiring manager understands within seconds that this is a documentation-grade site built by someone who treats QA as an engineering discipline. They believe the AI-driven claims because they're presented with the same rigor as an API reference, not marketing copy. They act via the sidebar's "Get in touch" panel or the résumé/LinkedIn links.

FIRST VIEWPORT: Left sidebar (fixed, ~280px desktop): wordmark "RJI", nav list (Overview, Experience, Skills, Awards, Remote Work, Contact), status chip pinned at the bottom. Right column, generous top margin: H1 using the resume title verbatim, one-line positioning statement, then a code-block panel showing a condensed real snippet of the AIDLC pipeline stages (design review → script dev → code review → merge), with a primary "Get in touch" button and secondary "View résumé" link inline beneath it — no separate hero photo/illustration; the code panel is the hero. Signature interaction: hovering/tapping a pipeline stage inside that code panel highlights the matching sidebar nav item and opens a small reference tooltip with that stage's real detail, mirroring how docs sites cross-link code to reference.

FORM: Developer Docs world — index 4 of 7 on the ordered candidate list; direction seed key f9fa1b12 (assigned, mode persuade, chosen by the user over the CI/CD-pipeline pick, the oscilloscope challenger, and the conventional-portfolio standing exit).

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
